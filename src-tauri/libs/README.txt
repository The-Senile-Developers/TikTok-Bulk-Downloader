This folder expects the following binaries:

- ffmpeg.exe
- yt-dlp.exe

They are not committed to this repository because the files are too large to push and version here reliably.

Download them from their official release repositories instead:

- FFmpeg: https://github.com/GyanD/codexffmpeg/releases or https://www.gyan.dev/ffmpeg/builds/
- yt-dlp: https://github.com/yt-dlp/yt-dlp/releases

After downloading, place ffmpeg.exe and yt-dlp.exe in this libs folder.
